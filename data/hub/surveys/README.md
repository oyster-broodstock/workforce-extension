# Adoption surveys (survey_responses) - no data in this repo

`survey_responses` is a **Restricted** table (Charter s4; IRB). Respondent-level files are never committed to GitHub,
mock or real. They are held by PSI/Walton and the UW hub. Only de-identified aggregates approved for release are placed
in `../../hub/` once available.

Schema: Data Dictionary v0.1, table `survey_responses` (respondent_code, survey_round, operation_type, region,
question_id, response). Codebook ownership is open question OQ-12.
